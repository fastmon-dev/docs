Fastmon ist ein gehosteter Service. Auf deinen Servern installierst
du nichts; du baust ein `<script>`-Tag in deine Site ein, das auf
deine Fastmon-Site zeigt. Etwa fünf Minuten Arbeit.

Ein einzelnes Tag im `<head>` läuft auf jeder Site, die du
kontrollierst: egal ob statisches HTML, Next.js, WordPress, Hugo
oder über einen Tag-Manager.

## Was alle Setups gemeinsam haben

Das Script, das du einbettest, ist bis aufs Byte derselbe Inhalt,
egal wie du es lädst:

```html
<script src="https://fastmon.site/s/{source_hash}.js" defer></script>
```

`{source_hash}` ist der Per-Site-Hash, den Fastmon beim Anlegen der
Site erzeugt hat. Aus den Site-Einstellungen kopieren.

Der Tracker:

- registriert `PerformanceObserver` für Web Vitals,
- puffert Events im Speicher und
- schickt gebündelte POSTs an `/c/{collector_hash}`, verteilt
  über den Lebenszyklus des Pageviews: beim Laden, bei
  `pagehide`, `visibilitychange → hidden` und in periodischen
  Flushes.

Er setzt keine Cookies, speichert keine IPs und macht kein Fingerprinting.
Volles Statement in [Privacy](/de/privacy).
