Fastmon ist ein gehosteter Service. Auf deinen Servern musst du
nichts installieren — du fügst einfach ein `<script>`-Tag in deine
Site ein, das auf deine Fastmon-Site zeigt. Wähle den Pfad unten,
der zu deinem Stack passt; jeder ist self-contained und dauert
etwa fünf Minuten.

Wenn dein Stack nicht dabei ist: der
[HTML-Pfad](/de/install/html) ist der universelle — ein einzelnes
Tag im `<head>` funktioniert auf jeder Site, die du kontrollierst.

## Was alle Setups gemeinsam haben

Das Script, das du einbettest, ist Byte-für-Byte derselbe Inhalt,
egal wie du es lädst:

```html
<script src="https://api.fastmon.eu/s/{source_hash}.js" async></script>
```

`{source_hash}` ist der Per-Site-Hash, den Fastmon beim Anlegen der
Site erzeugt hat. Aus den Site-Settings kopieren.

Der Beacon:

- registriert `PerformanceObserver` für Web Vitals,
- puffert Events im Speicher und
- schickt einen gebündelten POST an `/c/{collector_hash}` bei
  `pagehide`, `visibilitychange → hidden` oder einem periodischen
  Flush.

Er setzt keine Cookies, speichert keine IPs und fingerprinted nicht —
volles Statement in [Privacy](/de/privacy).
