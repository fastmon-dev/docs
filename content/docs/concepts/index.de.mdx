## Wie die Teile zusammenhängen

```
Organisation
 ├── Mitglieder (mit Rollen)
 ├── API-Tokens
 ├── Notification Rules
 └── Applications
      ├── source_hash + collector_hash   (Beacon-URLs)
      ├── Tracker-Einstellungen (Preset, Collector, site_policy)
      ├── Releases
      └── Sites (Domains)
           ├── domain
           ├── Per-Domain-Overrides (Retention, store_stitch, …)
           └── Tags
```

Beacon-Daten gehen vom Browser direkt in unseren Analytics-Store und sind dann fürs Dashboard oder die API abfragbar.
