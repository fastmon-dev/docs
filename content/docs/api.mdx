The Fastmon REST API is the same surface the dashboard uses. It's
auto-generated from code and shipped as an OpenAPI document at
[`/openapi.json`](https://api.fastmon.eu/v1/openapi.json) — drop it into
your favorite generator (`openapi-typescript`, `oapi-codegen`, …)
for a typed client.

This section is the human-readable companion. The OpenAPI document
is authoritative for exact field shapes.

## Base URL

```
https://api.fastmon.eu/v1
```

Public ingest endpoints (`POST /c/{collector_hash}` and
`GET /s/{source_hash}.js`) live **outside** the `/api/v1/` prefix
and have their own contract.

## Conventions

- **IDs are UUID v7** strings — sortable by creation time.
- **Timestamps are ISO-8601 UTC with `Z`**.
- **Single resources** are returned raw; **lists** wrap with
  `data` + `meta`; **errors** wrap with `error`. See
  [Errors](/en/api/errors).
- **Default limit** is 50; max is 100 on every list endpoint.
- **`X-Request-ID`** is on every response. Mirror it back when
  reporting issues.
