          untouched.


          Open only to someone who holds what the key holds: an owner-grade key
          is not

          editable by a member, not downwards and not even to rename it.
          Revoking it

          stays open to them, which is the move that matters when a key is
          suspected.

          The reasoning is in `_require_authority_over`.


          Within that, step-up is asked only when the edit gives the key MORE
          than it

          had - a scope it did not carry, or a later expiry. Both are
          re-granting

          authority and are a mint in all but name. Narrowing and renaming pass

          without a factor. The ceiling for a widening is what the person
          editing

          holds today, never what the original minter held.
