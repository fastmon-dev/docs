Die Fastmon-REST-API liefert dieselbe Oberfläche, die das Dashboard
nutzt. Wird aus dem Code generiert und als OpenAPI-Dokument unter
[`/openapi.json`](https://api.fastmon.eu/v1/openapi.json) ausgeliefert —
direkt in deinen Generator deiner Wahl für einen typisierten Client.

## Base URL

```
https://api.fastmon.eu/v1
```

Die öffentlichen Ingest-Endpunkte (`POST /c/{collector_hash}` und
`GET /s/{source_hash}.js`) liegen **außerhalb** des
`/api/v1/`-Prefix.

## Konventionen

- **IDs sind UUID v7** — nach Erzeugungszeit sortierbar.
- **Zeitstempel sind ISO-8601 UTC mit `Z`**.
- **Einzelne Ressourcen** werden direkt zurückgegeben; **Listen**
  wrappen mit `data` + `meta`; **Fehler** wrappen mit `error`.
  Siehe [Fehler](/de/api/errors).
- **Default-Limit** 50, Max 100 auf jedem List-Endpunkt.
- **`X-Request-ID`** auf jeder Response. Beim Reporting
  zurückgeben.
