# Same stance as the main site (https://fastmon.eu/robots.txt): search engines

#
# Machine readable overviews for LLMs and AI assistants:
#   https://docs.fastmon.eu/llms.txt       (index of every page)
#   https://docs.fastmon.eu/llms-full.txt  (full page text)
#
# Every docs page also has a markdown twin, linked from the page itself via the
# "copy markdown" button.
#
# Marketing site and pricing: https://fastmon.eu/
#
# Content Signals (contentsignals.org, draft-romm-aipref-contentsignals):
#   search   = build an index, link us, quote short excerpts
#   ai-input = feed us into a model at query time (RAG, grounding, AI answers)
#   ai-train = train or fine-tune models on us
# All three are yes, which matches the crawler rules below. The line is
# repeated per group on purpose: a crawler obeys only the most specific group
# that matches it, so a signal under "*" alone would never reach GPTBot.

User-agent: *
Allow: /
Content-Signal: search=yes, ai-input=yes, ai-train=yes
